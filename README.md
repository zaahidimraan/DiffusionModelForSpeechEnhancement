# Speech Enhancement Model Testing Repository

This repository is designed to facilitate the testing and evaluation of various speech enhancement models. It provides a structured framework for comparing different models, analyzing their performance under various conditions, and visualizing results.

## Installation

1. **Create a Virtual Environment:**
   * It's highly recommended to create a virtual environment to manage your project's dependencies. 
   * Navigate to your project directory in the terminal and run:

     ```bash
     python3 -m venv venv  # Create the virtual environment
     ```

   * Activate the virtual environment:

     ```bash
     venv/bin/activate      # On Windows
     ```

2. **Install Requirements:**

   * With the virtual environment activated, install the required Python packages:

     ```bash
     pip install -r requirements.txt
     ```

3. **Follow the Demo:**

   * Open and follow the `demo.ipynb` Jupyter Notebook to understand how to use the speech enhancement model for testing.
